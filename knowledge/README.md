# Knowledge — the sources data is taken from

This is where the profession's sources **to be cited** go: laws, price lists, forms,
databases, guidelines of the professional body, official templates. At first it is empty:
Claude fills it during `setup` (study of the profession) and when it learns a new type of
job.

Rules:
- one subfolder per source (e.g. `price-list-2026/`, `city-forms/`);
- every source has a line below: what it is, where it comes from (link), download date,
  how long it is valid, how to cite it;
- sources are not modified: they are read and searched. If a source is outdated, the new
  version is added next to it (the old one stays) and the user is told;
- only official sources, or sources whose licence allows them to be used.
