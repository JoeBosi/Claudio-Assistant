# Privacy policy — Claudio-Assistant

Last updated: 15 October 2026

## Summary
Claudio-Assistant has **no server and collects nothing**. The author receives no data of any kind.

## What the plugin does
The plugin contains one skill that copies the template files into a folder the user chooses
on their own computer. It sends nothing over the network.

## Data stored by the assistant it creates
The assistant folder keeps working memory (for example the user's profile, clients,
suppliers, job cards) as plain text files **inside that folder, on the user's computer only**.
It is written only with the user's OK, can be removed at any time with the `forget` skill or
by deleting the files, and is never sent to the author or to any third party by the plugin.
Sensitive data (health, ID documents, bank details) is never copied into memory.

## Third parties
- Conversations go through Anthropic's Claude service, under the user's own Claude account
  and Anthropic's terms and privacy policy.
- When the assistant searches the web or installs free programs, it contacts public websites
  and package managers. Its rules forbid typing client data into websites.

## Retention
The author retains nothing. Files on the user's computer stay until the user deletes them.
