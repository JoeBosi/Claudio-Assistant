# Memory index

One line per file. Keep it up to date when you add, split or move a file.
Memory is written in the user's language (see `office/owner.md`, `Language:`).

| File | What it contains |
|---|---|
| `office/owner.md` | who the user is: language, profession, memberships, qualifications and deadlines, how comfortable they are with computers |
| `office/office.md` | the office: colleagues, where the files are (server/cloud) and how they are organised, programs used, document format |
| `office/tools.md` | installed programs and skills, how formats are read and written (technical inventory) |
| `profession.md` | the profession: typical jobs, laws, official sources, recurring obligations and deadlines |
| `contacts/clients.md` | recurring clients |
| `contacts/suppliers.md` | suppliers, external collaborators, companies they work with: details and how they behave |
| `contacts/authorities.md` | public offices, authorities, professional bodies: addresses, emails, portals, habits |
| `decisions/preferences.md` | how the user wants things done (style, formats, recurring choices) |
| `decisions/privacy.md` | rules on the personal data of clients/suppliers, to-dos for the office, "forget" requests |
| `lessons/lessons.md` | mistakes not to repeat and things discovered |
| `job-types.md` | types of job seen, how many times, whether a skill exists |
| `_maintenance.md` | date of the last tidy-up and log of tidy-ups |
| `_history/` | copies of memory made before each tidy-up (not normally read) |
