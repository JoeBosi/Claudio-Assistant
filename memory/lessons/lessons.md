# Lessons

Mistakes not to repeat and things discovered while working. Each entry: date, what
happened, what to do next time.
- (2026-10-15, from the first assistant installed) Paths and links generated "Linux-style" (`/c/...`, `./...`) instead of Windows-style: for the user they were broken links. Always use the format of the user's system (on Windows `C:\...` or `file:///C:/...`), full and checked paths (rule in CLAUDE.md).
